Internal vs External Links

Every item in the nav bar above is an internal link: it uses a fragment identifier (#id) that jumps to a section with a matching id on this same page, so it never leaves the document. The gallery link is also internal in the broader sense - it points to another page within the same site (Q4_gallery.html). The contact section, by contrast, contains an external link to the university's own domain (kmclu.ac.in) and a mailto link that hands off to the user's email client rather than staying inside the browser at all.
