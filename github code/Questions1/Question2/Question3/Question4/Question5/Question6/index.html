Why semantic elements instead of generic div

A generic div carries no meaning - it tells the browser and assistive technology nothing about what the content inside it is. Elements like header, nav, main, article, aside and footer describe the role each region plays. This lets a screen reader announce landmarks ("navigation", "main content") so a user can jump straight to the part they want, lets search engines weight content correctly, and makes the raw markup far easier for another developer to read without hunting through a sea of identically named div wrappers.
