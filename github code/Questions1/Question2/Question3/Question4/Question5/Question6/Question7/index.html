Why character references are useful

Some characters, such as < and &, are part of HTML's own syntax, so typing them directly can confuse the browser into thinking a tag or an entity is starting. A character reference lets the browser display the character literally instead of interpreting it. Character references are also useful for symbols that are hard or impossible to type directly on a standard keyboard - mathematical notation like &sum; or &infin;, typographic quotation marks, and symbols like © or ™ that carry specific legal meaning and should render consistently regardless of the page's text encoding.
