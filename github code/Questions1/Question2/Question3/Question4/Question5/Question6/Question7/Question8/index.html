Frames: Old Approach vs Modern Design

Old approach (Frameset)

<frameset cols="20%,80%">
  <frame src="nav.html">
  <frame src="content.html">
</frameset>

Splits the browser window into separate HTML documents. Deprecated, bad for SEO, accessibility and browser history.

Modern approach (Semantic HTML + CSS)

Home | Courses | Contact

All content stays in one document, laid out using nav and main tags with CSS instead of frames.
