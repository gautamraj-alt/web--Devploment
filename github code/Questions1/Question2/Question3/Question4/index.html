Note Accessibility

Each image above has explicit width and height attributes so the browser can reserve the right amount of space before the image finishes loading - this prevents the page layout from jumping around, which is disorienting for every reader and especially for anyone using screen magnification. Oversized, unoptimised images also slow the page down on mobile data, which is an accessibility issue in itself. The alt text on each image is not a repeat of the caption: it describes what is actually happening in the picture so a screen-reader user gets the same information a sighted visitor gets from looking at it, while the figcaption supplies the human-readable caption for everyone.
